# Phase 1 — CARLA Simulation Baseline

This phase establishes the simulation foundation for the project using the CARLA autonomous driving simulator. It implements YOLOv8n object detection, LiDAR and radar sensor fusion, TTC-based emergency braking logic, and tests across adverse weather conditions in Town04.

## Setup and Requirements

### Prerequisites

- Python 3.8 or later
- CARLA simulator 0.9.13 or later ([carla.org](https://carla.org/))
- CARLA Python API (included with the CARLA installation)

### Python Dependencies

```bash
pip install numpy opencv-python matplotlib ultralytics pygame
```

For YOLOv8 specifically:

```bash
pip install ultralytics
```

### Running CARLA

Start the CARLA server before running any script:

```bash
# Windows
CarlaUE4.exe

# Linux
./CarlaUE4.sh
```

CARLA runs on `localhost:2000` by default. All scripts connect to this address.

## What the Simulation Tests

- **Town04** map (CARLA's highway/suburban environment)
- Single and multiple static/dynamic obstacle scenarios
- Adverse weather: heavy rain, reduced visibility, headlights-on conditions
- YOLOv8n detection performance under normal and degraded visual conditions
- TTC-based emergency braking trigger thresholds
- LiDAR and radar sensor fusion producing a combined collision risk verdict

## Output Data

All videos and CSV logs are generated by running the scripts against a live CARLA instance — they are not included in the repository. Running any of the obstacle scripts will produce MP4 output files and the following CSV logs in the working directory:

| File | Contents |
|---|---|
| `sensor_fusion.csv` | Frame-by-frame fusion verdict (SAFE / CAUTION / IMMINENT) |
| `radar_data.csv` | Raw radar range and velocity readings |
| `vehicle_state.csv` | Speed, position, and braking state per frame |
| `yolo_performance.csv` | Detection confidence and class per frame |
| `comprehensive_analysis.png` | Summary chart across all sensor metrics |
